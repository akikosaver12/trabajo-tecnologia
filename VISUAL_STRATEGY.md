# Estrategia Visual y Neuro‑diseño

## 1. Identidad Visual

El diseño se enfoca en una estética **Tech Dark Mode** (modo oscuro tecnológico) y premium, orientada a profesionales, desarrolladores y emprendedores. Utiliza efectos de vidrio (glassmorphism), bordes finos con degradados y sombras suaves para dar profundidad.

La interfaz busca transmitir:
- **Innovación y Futuro**: A través de acentos de color vibrantes (Cyan y Violeta/Indigo).
- **Confianza y Profesionalismo**: Mediante un fondo oscuro sobrio, tipografía geométrica limpia y un espaciado equilibrado.

## 2. Paleta de Colores y Psicología

- **Fondo Principal**: Slate Oscuro (`#0B0F19`) - Transmite estabilidad, sobriedad y reduce la fatiga visual.
- **Primario / Acento Principal**: Indigo Eléctrico (`#6366F1`) - Asociado con el intelecto, la tecnología avanzada y la creatividad.
- **Secundario / Acento Secundario**: Cyber Cyan (`#06B6D4`) - Aporta energía visual, frescura y modernidad.
- **Superficie de Tarjetas**: Slate Semitransparente (`rgba(30, 41, 59, 0.5)`) con efecto `backdrop-filter: blur(12px)` para lograr el efecto cristalizado (glassmorphism).
- **Bordes y Delimitadores**: Blanco Translúcido (`rgba(255, 255, 255, 0.08)`) para contornos nítidos y elegantes.
- **Texto Primario**: Blanco Nieve (`#F8FAFC`) - Máximo contraste y legibilidad.
- **Texto Secundario**: Gris Frío (`#94A3B8`) - Reduce el contraste excesivo en textos largos.

## 3. Tipografía y Licencias

- **Títulos (Headings)**: *Outfit* (Google Fonts - SIL Open Font License). Es una tipografía geométrica moderna con curvas suaves y un aire futurista ideal para tecnología.
- **Cuerpo de texto (Body)**: *Inter* (Google Fonts - SIL Open Font License). Diseñada específicamente para interfaces de usuario en pantallas, garantizando una excelente legibilidad en cualquier tamaño.

## 4. Estructura de Activos (/assets)

- `/assets/logos/`: Contiene versiones vectoriales (.svg) de los logotipos.
- `/assets/icons/`: Iconos minimalistas tipo Lucide.
- `/assets/images/`: Imágenes de soporte optimizadas.
- `/assets/fonts/`: Archivos de fuentes locales en caso de requerirse carga offline.
